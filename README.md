# Citas Dentales 🦷

Sistema web de gestión y agendamiento de citas odontológicas para optimizar la organización de horarios y la atención a pacientes.

## 📌 Descripción del Proyecto
Este software permite a los clientes agendar citas dentales de forma interactiva y al personal administrativo controlar la disponibilidad de la clínica.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** React.js (construido con Vite)
* **Backend:** Node.js + Express.js
* **Base de Datos:** MySQL (administrada mediante Laragon)
* **Control de Versiones:** Git & GitHub

## 🚀 Guía de Instalación Local

### Requisitos Previos
* **Node.js** (v18 o superior)
* **Laragon** (con los servicios de Apache y MySQL activos)
